Mismatch rate went 100% → 25% → 10% → **0%** across four real runs as each bug was found and fixed; confirmed stable (0%) across two independent random samples once fixed. This is a genuine validation of G1.4's scoring data, not a rubber stamp — it would have caught real hallucination if any existed.
